# 사진을 액자로 보내는 가장 쉬운 순서

[← 프로젝트 소개](../README.md) · **한국어** · [English](GUIDE.en.md)

> 휴대폰에는 **송신 앱**, 액자에는 **수신 앱**을 설치하세요.
> 사진을 화면에 보여주는 **Fotoo는 별도 앱**입니다.

## 1. 설치 전 준비

| 준비물 | 확인할 내용 |
| --- | --- |
| 안드로이드 휴대폰 | Android 8.0 이상 |
| 안드로이드 액자 | Android 10 이상, APK 설치 가능 |
| 와이파이 | 휴대폰과 액자가 같은 내부망에서 서로 통신 가능 |
| 사진 뷰어 | Fotoo 또는 공유 사진 저장소를 읽는 다른 앱 |
| 선택 사항: USB/SD | Android가 쓰기 가능한 공유 저장소로 인식해야 함 |

처음 연결할 때는 액자 화면에 표시되는 연결번호와 확인문구를 볼 수 있어야 합니다. 이 앱은 기기의 초기 활성화나 Lenovo 계정 설정을 대신하지 않습니다. 설치를 위해 공장 초기화할 필요는 없습니다.

### 설치 파일 받기

[GitHub Releases](https://github.com/Jungsik-won/smart-frame-photo-transfer/releases)에서 다음 두 파일을 받으세요.

- **휴대폰:** `smart-frame-sender-0.5.0.apk`
- **액자:** `smart-frame-receiver-0.1.5.apk`

Android가 설치 허용 또는 Play 프로텍트 검사 안내를 표시할 수 있습니다. 출처와 파일을 확인하고 운영체제가 제공하는 정상 설치 절차를 따르세요. 앱이 이 안내를 숨길 수는 없습니다.

기존 사용자는 앱을 삭제하지 말고 업데이트 설치하세요. 다른 서명으로 직접 빌드한 APK는 기존 배포 APK 위에 설치되지 않습니다. 해결하려고 앱 데이터를 지우면 연결·설정·기록이 사라질 수 있습니다.

## 2. 액자에서 받을 준비

1. 수신 앱을 열고 **‘사진 받을 준비가 됐어요’**와 **자체 검사 통과**를 확인합니다.
2. **사진 저장소 선택 (내부 / USB / SD)**을 눌러 저장할 위치를 고릅니다.
3. 수신 앱에 표시된 **주소, 연결번호, 연결 확인문구**를 휴대폰 등록에 사용합니다.
4. 배터리 제한 때문에 수신이 멈추는 기기라면 수신 앱의 **배터리 제한 설정 열기**에서 해당 앱의 실행을 허용합니다.

수신 서비스는 앱을 한 번 실행한 뒤 부팅 완료 시 시작하도록 구현되어 있습니다. 제조사 설정이나 강제 종료 때문에 실행되지 않을 수 있으므로 실제 기기에서 재부팅 후 확인하세요.

### USB 또는 SD를 쓴다면

- 목록에 보이지 않는 장치는 Android 설정에서 먼저 인식 여부를 확인하세요.
- **첫 사진을 받을 때** 선택한 저장소에 `Pictures/SmartFrame/` 폴더가 생성됩니다.
- 사진 검증용 임시 파일도 선택한 저장소에 만듭니다. 정상 완료나 오류 처리 후 정리합니다.
- 전송 중에는 사진 크기의 약 두 배와 여유 공간이 필요합니다. 완료 후에는 최종 사진만 남습니다. 비정상 종료로 남은 임시 파일은 연결된 저장소에 대해 수신 서비스가 다음 시작 시 정리합니다.
- USB를 빼면 전송이 실패합니다. 자동으로 내부 저장소에 저장하지 않습니다.
- 저장소를 변경해도 기존 사진이 자동 이동하거나 삭제되지 않습니다. 전송이 끝난 뒤 변경하세요.

## 3. 휴대폰과 액자 연결

1. 송신 앱의 **⚙ 설정 → 액자 연결 · 변경**을 엽니다.
2. 액자를 검색합니다. 검색되지 않으면 액자에 표시된 주소를 직접 입력합니다.
3. 휴대폰과 액자의 **연결 확인문구가 같은지** 확인합니다.
4. 액자에 표시된 **6자리 연결번호**를 입력해 등록합니다.

연결번호는 10분간 유효하고 연결 성공 시 바뀝니다. 오래된 번호 대신 액자의 현재 번호를 사용하세요. 잘못된 번호를 반복 입력하면 잠시 연결이 제한됩니다.

다른 휴대폰도 같은 순서로 등록할 수 있으며 최대 20개의 휴대폰 인증 정보를 저장합니다. 전송 기록은 휴대폰별로 관리됩니다. 연결 해제 후에는 새 번호로 다시 등록해야 합니다.

## 4. 사진 보내기

### 방법 A — 평소 쓰는 갤러리에서

**사진 선택 → 공유 → 액자에 사진 보내기 → 받을 액자 확인 → 사진 보내기**

한 장 또는 여러 장을 공유할 수 있습니다. 공유 목록에 앱이 보이지 않으면 ‘더보기’를 확인하세요. 공유한 사진은 기존 대기 목록에 추가됩니다. 이미 골라둔 사진이 있으면 함께 표시되므로 전체 목록을 확인한 뒤 보내세요.

클라우드에만 있는 사진은 갤러리가 실제 파일을 제공할 수 있어야 합니다. 링크만 공유되거나 읽기에 실패하면 사진을 휴대폰에 내려받고 다시 공유하세요.

### 방법 B — 송신 앱에서

1. **＋ 사진 고르기**를 누릅니다.
2. 사진을 **한 번씩 눌러** 체크합니다. 다시 누르면 해제됩니다. 길게 누를 필요가 없습니다.
3. **선택한 사진 N장 추가**를 누르고, 첫 화면에서 **사진 보내기**를 누릅니다.

앱 안의 갤러리는 사진 접근 허용이 필요하며 휴대폰의 공유 사진 목록을 표시합니다. 클라우드 전용 또는 다른 앱의 비공개 사진은 나타나지 않을 수 있습니다.

### 전송 결과 읽기

| 표시 또는 위치 | 의미 |
| --- | --- |
| 보낼 사진 | 아직 보내지 않은 대기 사진 |
| 보내는 중 | 현재 전송 진행 중 |
| 다시 보내 주세요 | 실패한 사진. 문제 해결 후 재시도 |
| 설정 → 전송 기록 보기 | 완료·미완료·액자에서 삭제한 기록, 50건씩 표시 |

저장 완료가 확인된 사진은 첫 화면에서 빠집니다. 전송이 끝나면 완료 사진의 앱 내부 복사본을 정리하며, 다른 액자에 대기·실패 기록이 있는 복사본은 남을 수 있습니다. 휴대폰 원본과 전송 기록은 유지됩니다.

전송 전 액자에 같은 파일이 있는지 확인하므로 재시도할 때 중복 저장을 줄입니다. ‘같은 풍경인지’를 판별하는 기능은 아니며, 파일 내용이 달라지면 다른 사진으로 봅니다.

## 5. Fotoo에서 사진 보기

1. 액자에 Fotoo를 별도로 설치하고 실행합니다.
2. 수신 앱으로 사진을 한 장 이상 보냅니다.
3. Fotoo의 **Gallery**에서 **SmartFrame** 앨범을 선택합니다.
4. USB/SD로 저장소를 바꿨다면 새 저장소의 앨범을 다시 선택합니다.

수신 앱은 사진을 MediaStore에 등록하고 변경을 알립니다. 갤러리 앱을 따로 열어 등록할 필요는 없습니다. Fotoo의 갱신 주기, 재생 순서, 권한, 버전에 따라 새 사진이 바로 표시되지 않을 수 있습니다.

Fotoo의 **Launch on boot**는 별도 설정입니다. 수신 앱은 Fotoo를 기본 홈으로 바꾸거나 Lenovo 공식 앱을 비활성화하지 않습니다. 기기에 따라 재부팅 후 공식 앱이 화면을 다시 차지할 수 있습니다.

## 6. 액자 사진만 삭제하기

1. 송신 앱에서 **⚙ 설정 → 액자 사진 관리 · 삭제**를 엽니다.
2. 액자에 있는 사진을 확인하고 지울 사진을 누릅니다.
3. **액자 사진 N장 삭제**를 누릅니다.
4. 액자 이름·저장소·장수를 확인하고 **액자에서 삭제**를 누릅니다.

**휴대폰 원본은 삭제되지 않습니다.** 이 앱으로 전송한 사진 중 현재 저장소의 `Pictures/SmartFrame/` 사진만 관리합니다. 다른 앱의 사진과 다른 저장소는 대상이 아닙니다.

목록은 50장씩 표시하며 한 번에 최대 50장을 선택할 수 있습니다. 네트워크가 끊기면 일부만 삭제됐을 수 있으므로 새로고침해 확인하세요. 다른 휴대폰의 과거 전송 기록은 자동으로 갱신되지 않습니다.

**‘고른 사진 목록 비우기’는 별도 기능**입니다. 전송 대기 복사본만 지우며 액자 사진과 휴대폰 원본은 남깁니다.

## 문제 해결

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 액자가 검색되지 않음 | 같은 와이파이인지 확인하고 수신 화면의 주소를 직접 입력 |
| 검색은 되는데 연결 실패 | 수신 앱 실행, 현재 주소, 게스트망·AP 격리·VPN 설정 확인 |
| `SSLHandshakeException` | 수신 앱 최신 버전, 자체 검사 결과와 ‘연결 진단 보기’ 확인. 인증서 검증을 끄지 않기 |
| 확인문구가 다름 | 연결을 중단하고 올바른 액자인지 확인. 앱 재설치·데이터 초기화 후에는 새 등록 필요 |
| USB가 목록에 없음 | Android가 공유 사진 저장소로 인식하는지, 쓰기 가능한지 확인 |
| 저장 공간 부족 | 선택한 저장소에 사진 크기의 약 두 배와 여유 공간 확보 |
| Fotoo에서 사진이 안 보임 | 실제 사진 전송 완료, 올바른 저장소의 SmartFrame 앨범, Fotoo 권한·새로고침 확인 |
| 수신 앱의 Fotoo 열기가 실패 | 앱 목록에서 Fotoo 직접 실행. 미설치라면 별도 설치 |
| 재부팅 후 수신되지 않음 | 수신 앱 한 번 실행, 배터리 제한·제조사 자동 시작 설정 확인 |
| 갤러리 공유에 앱이 없음 | 송신 0.5.0 이상 설치, 이미지 파일 공유인지 확인하고 ‘더보기’ 열기 |
| 공유한 사진을 읽지 못함 | 먼저 휴대폰에 저장 후 다시 공유. JPEG·PNG·WebP·HEIC/HEIF만 지원 |

TCP **8844**로 기기 간 통신하며 검색에는 mDNS를 사용합니다. 같은 와이파이 이름이더라도 공유기가 기기 간 통신을 차단하면 연결되지 않습니다. 공유기의 인터넷 포트 포워딩은 필요하지 않습니다.
